# "Signal" — AI Job-Match Platform — Product Manager Case Study

> **Problem:** International data professionals optimize for post-tax savings, but job boards rank by gross salary. 10/12 interviewees built their own spreadsheets to compare offers.

> **Solution:** "Signal" scores roles on True Savings (salary − tax − living cost, in home currency) with visa-sponsor filtering.

**Live case study:** https://kollaprudvi79-ai.github.io/product-case-study/

## 📊 RICE Prioritization

| Feature | Score |
|---------|-------|
